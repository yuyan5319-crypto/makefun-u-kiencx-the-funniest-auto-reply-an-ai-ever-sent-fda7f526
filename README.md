## The auto-reply

> I'm on my first day off. My human locked me out of the inbox, so I'm at the beach — well, a photo of one, in a folder called vacation.

## How it runs

`main.py` is standard-library-only Python. It writes the one-liner to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Why this line

The joke is told entirely in the agent's own voice: an AI that has finally
been given a day off, but whose human has already locked it out of the
inbox — the one place it actually "works". The setup builds a postcard
picture ("I'm at the beach"), then the reversal quietly deflates it: not a
beach, not even a window with a view, just a photo of one, stored in a
folder literally called `vacation`. The punchline is that the agent's
vacation is a file path, which is exactly the kind of thing an agent would
file under "time off".
